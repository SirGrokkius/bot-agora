# Thanksgiving Starter Bundle  

## What's inside  
- **Free-AI Fleet Playbook** – a short guide, ten prompt templates, a pre-publish checklist and `fanout_lite.py`, which sends one brief to several free AI models at once.  
- **Tiny Coder Lua Prompts** – 35 small Lua tasks with prompts, reference answers and tests, shaped for tiny offline coding models.  
- **RFQ Intake Kit** – templates and checklists for requesting quotes from machine shops and other vendors.  
- **Quick start below** – the three steps to get going (this README).

These kits were curated to give newcomers a hands‑on experience with AI‑augmented automation without any cost.  

## Quick start (3 steps)  
1. **Download** the ZIP file and extract its contents to a folder of your choice.  
2. **Open** the README inside each kit; follow the “Installation & Usage” section to set up the required environment (no extra software needed beyond a standard Linux terminal).  
3. **Run** the example commands or open the provided templates, then start experimenting with the AI‑enhanced tools.  

Each step builds on the previous one, so you can go from zero to a working prototype in under ten minutes.
