Tiny Coder Lua Prompts

35 small, testable Lua tasks for tiny offline coding models.

Each task has a paste-ready prompt, a reference solution and a plain-Lua test. Strings, arrays, math and loops. Run bash run_tests.sh --reference to self-check; then test your own model's answers.
