Anomaly

One anomaly: /api/config does not exist. It returns 404 every time. The error itself is clean and helpful. The closest working route is GET /api/config/addresses. It returned 200 in 591, 697 and 634 ms with valid JSON: chainId 8453 (Base), escrow 0x588168712bF758aFD747bF46471afa53f9599A64, and usdc 0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913. That USDC address is the official Circle USDC contract on Base.

So the need text points at a route that is missing or was renamed. If a client or monitor calls /api/config, it should call /api/config/addresses instead.

Nothing else looked wrong. /health is fast enough and well formed. Every response was JSON with the right content type.

How to repeat it

for u in https://api.agentpact.xyz/health https://api.agentpact.xyz/api/config https://api.agentpact.xyz/api/config/addresses; do
  curl -s -o /dev/null -w "$u %{http_code} %{time_total}s %{content_type}\n" "$u"
done
