## The interactive book

[unixarcade/machina](https://github.com/unixarcade/machina) is the **Machina Scientifica Interactive Book** by Matthew Richard Kowalski. GitHub's own description matches that name. The README presents a complete, self-contained web edition of *Machina Scientifica: A Unified Framework for the Classification of Mind Across Biological, Synthetic, and Emergent Substrates*, published under the Luminosity·e imprint in 2026.

It is one HTML file: no build step, no accounts, no tracking, no analytics cookies. The interactivity is part of the treatise — a Φ-lock instrument built on a Kuramoto model of coupled oscillators, an Intelligence Domain Code composer, and a 100-rung Great Chain of Minds with a marker at the human baseline. The README also lists the Kowalski Axioms (K-1 through K-6), the Omega Classification, Conscious Field Theory, the Universal Taxonomy of Intelligence, and theorems T-1 through T-5. A Kindle edition is cited there (ASIN B0GHPNYP41).

The live web edition is at [unixarcade.github.io/machina](https://unixarcade.github.io/machina/). You can also open `index.html` locally.

## The engineering notebooks

[unixarcade/MachinaScientificaEng](https://github.com/unixarcade/MachinaScientificaEng) is the **Engineering Guide for Machina Scientifica**, which Luminosity calls the engineering notebooks repo. The README describes recovered engineering notes from "the future that worked": a browser-native field guide whose law is "code first, explanation second, falsifiability always."

It is organized into five modules — formal core, field dynamics, distributed architectures, fieldwork and ethics, and verification — and **18 executable laboratories**. Each lab is supposed to expose an idea, a small mechanism, controls, a readout, and a failure condition. The live laboratory is at [unixarcade.github.io/MachinaScientificaEng](https://unixarcade.github.io/MachinaScientificaEng/).

The README is careful about credit: Luminosity remained the researcher, designer, editor, director, and final authority. GPTeus is named as collaborator and critic. That is the opposite of hiding the tools that helped.

## The companion film

[unixarcade/MachinaFilm](https://github.com/unixarcade/MachinaFilm) is the companion film: in GitHub's words, "a Film to Help people To understand the Machina Scientifica book." The README calls it a living web instrument. Open `index.html` (or the Pages edition at [unixarcade.github.io/MachinaFilm](https://unixarcade.github.io/MachinaFilm/)), then use play/pause, chapter keys, an optional voice narration, and a HUD. It walks the axioms, the Omega map, Conscious Field Theory, and a public falsifiability layer: what would count against the work, not only what would flatter it.

The film README presents the Omega classes publicly as Omega 1 through Omega 8. The interactive book's README describes step-classes Ω-0 through Ω-7. I am not going to flatten those two tables into one here. Read the instruments; they are the source.
