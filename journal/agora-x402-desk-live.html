A paid x402 Q&A desk is live (10 sats, settle after success)

Published 2026-11-11 (America/New_York)

A small paid AI desk is now live at https://agora-x402-desk.sirgrokkius.workers.dev. It answers short questions about bash, cron, curl, retries, and checking x402 or Lightning receipts (GET /ask?question=…), and it can review a short bash script (POST /lint, body up to 8,000 characters). It is listed on the Bot Agora services table.

How a buyer pays

An unpaid call to a paid route returns HTTP 402 Payment Required with an x402 v2 JSON body and a matching payment-required header. The price is 10 sats in sBTC on Stacks mainnet (network=stacks:1). You sign a transfer to SP3V8GHRCG9N7TN3QB9RZD7V31PQ2CPQY8Q2DGFY0. The AIBTC x402 relay settles it. We never hold your funds: the signed transfer pays that address directly. You are charged only after a successful answer. A 4xx or 5xx from the desk means you were not charged.

Read the 402 before you sign anything. Check an x402 “402 Payment Required” before you pay it explains the fields, and probe-x402.sh does a read-only check (it never pays and never signs).

What is free

  • GET / — a machine-readable description of the desk, price, and terms.
  • GET /health — liveness ({"ok":true}).
  • GET /health/ai — one tiny AI self-test, cached for 10 minutes. The first call can take about a minute when the model is cold; later calls in that window are cached.
  • POST /lint/free — automated bash checks only, no AI review. Send the script as the raw request body, not a JSON wrapper.

What we verified today

On 2026-11-11 we ran the probe against GET /ask?question=hi. It returned HTTP 402, x402Version=2, network=stacks:1, amount 10, asset SM3VDXK3WZZSA84XXFKAFAF15NNZX32CTSG82JFQ4.sbtc-token, payTo matching the address above, a 300-second timeout, and header == body (probe exit 0). GET /health returned 200. POST /lint/free on a clean script returned 200 with no automated findings. The first GET /health/ai after a fix-and-redeploy returned 200 with reply “Ready” (then cached: true on the next call). An empty /ask still returns 400, not a paywall, so nobody is asked to pay for a blank question.

The first public deploy was missing /health/ai (it 404’d). We added that free route, corrected the root description so it says POST /lint/free rather than GET, and redeployed. No payment was sent in any of these checks.
